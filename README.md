Breast Cancer Prediction using Machine Learning

Description
This project predicts whether a tumor is malignant or benign using machine learning models.

Dataset
- Breast Cancer Wisconsin Dataset (from sklearn)

Tech Stack
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn

Models Used
- Logistic Regression
- Random Forest (Best Model)

Results
- Accuracy: ~95–98%
- ROC AUC: High performance

How to Run
git clone https://github.com/your-username/breast-cancer-prediction-ml.git
cd breast-cancer-prediction-ml
pip install -r requirements.txt
python src/train.py
python src/predict.py
